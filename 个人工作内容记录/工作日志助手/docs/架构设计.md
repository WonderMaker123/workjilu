# 架构设计

> 适用对象：后续接手迭代的开发者。本文描述系统分层、目录契约、数据模型、接口清单与关键约定。
> 配套文档：[开发指南](./开发指南.md) · [部署运维手册](./部署运维手册.md)

## 1. 系统概览

面向个人/小组的工作日志应用：口语化随手记录 → AI 整理为书面条目 → 标签/日历/看板管理 → 周报月报一键生成与导出。多用户、数据按用户隔离，可完全内网私有化部署。

- 线上演示：支持域名反代部署或内网局域网部署
- 适用场景：个人日常工作梳理、研发/运维日常日志、团队周报月报快速汇总结算等

### 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3（`<script setup>` + TS）、Vite、Vue Router、Pinia、Element Plus、Axios、marked、docx（动态加载） |
| 后端 | Node.js 20、Express 4、TypeScript、Prisma 5、Zod、jsonwebtoken、bcryptjs |
| 数据库 | SQLite（单文件，Prisma 抽象，可平滑切 PostgreSQL） |
| AI | OpenAI 兼容协议（DeepSeek / 通义 / Kimi / Ollama 等均可），用户自配 baseUrl + key + model |
| 部署 | Docker Compose 两容器 + 宿主机 Nginx 反代 + Let's Encrypt |

### 请求链路

```
浏览器
  │  https://your-domain.com 或 http://IP:PORT
  ▼
宿主机 Nginx 容器（可选反代） / 直接访问
  │  proxy_pass http://127.0.0.1:18081
  ▼
worklog-web 容器（Nginx 静态资源 + /api 反代）
  │  /api/  →  http://server:3001
  ▼
worklog-server 容器（Express）
  ├── Prisma → /app/data/worklog.db（Docker 卷）
  ├── 图片文件 → /app/uploads（Docker 卷）
  └── AI 服务商（出站 HTTPS）
```

本地开发链路：Vite 5173 把 `/api` 代理到 `http://localhost:3001`（`VITE_PROXY_TARGET` 可覆盖）。

## 2. 目录契约

新增代码时**按职责放对应目录**，文件名即职责名，不新建自由发挥的目录。

```
工作日志助手/
├── docker-compose.yml            # 本地一键起（开发用）
├── docker-compose.prod.yml       # 生产编排
├── .env.production.example       # 生产环境变量模板（真实 .env 不入库）
├── README.md
├── docs/                         # 项目文档（本目录）
│
├── server/                       # ============ 后端 ============
│   ├── Dockerfile                # node:20-bookworm-slim（勿用 alpine，见运维手册）
│   ├── docker-entrypoint.sh      # 启动前自动 prisma migrate deploy
│   ├── .env.example
│   ├── prisma/
│   │   ├── schema.prisma         # 唯一数据模型真相源
│   │   └── migrations/           # SQL 迁移，只增不改，必须随 schema 提交
│   └── src/
│       ├── index.ts              # 进程入口：listen(PORT)
│       ├── app.ts                # Express 组装：中间件、静态目录、路由挂载
│       ├── middleware/
│       │   └── auth.ts           # JWT 校验中间件 + signToken()
│       ├── lib/                  # 基础设施（无 HTTP 语义、可被任意路由复用）
│       │   ├── prisma.ts         # PrismaClient 单例
│       │   ├── ai.ts             # OpenAI 兼容 chat() 客户端
│       │   ├── crypto.ts         # AI API Key 对称加解密
│       │   └── photos.ts         # 图片落盘/校验/路径穿越防护/清理
│       └── routes/               # 一个文件 = 一个资源域，只放路由与请求处理
│           ├── auth.ts           # 注册/登录/me/改密
│           ├── entries.ts        # 记录 CRUD、照片挂接、标签批处理
│           ├── photos.ts         # 图片读取（独立路由便于 <img> 引用）
│           ├── ai.ts             # 整理/月报/周报/续写
│           ├── aiConfig.ts       # 用户 AI 配置

│           ├── stats.ts          # 仪表盘统计
│           ├── backup.ts         # 数据导出/导入
│           └── logs.ts           # 运行日志查看/清空

└── web/                          # ============ 前端 ============

    ├── vite.config.ts            # 别名 @ → src，dev 代理，分包策略
    ├── .env.example              # VITE_API_BASE 等构建期变量
    ├── public/                   # 原样拷贝：icon.svg / manifest / sw.js
    └── src/

        ├── App.vue               # 根组件（仅 router-view）
        ├── assets/               # 全局样式：tokens.css 设计令牌、element-theme.css
        ├── api/                  # 后端接口封装（一个资源域一个文件，只定义类型+请求）
        │   ├── auth.ts  entries.ts  reports.ts
        │   ├── ai.ts  aiConfig.ts  stats.ts
        │   ├── backup.ts  logs.ts
        ├── lib/                  # 框架无关的工具能力
        │   ├── http.ts           # axios 实例：baseURL、Bearer 注入、401 退出、统一报错
        │   ├── speech.ts         # 语音识别封装
```

### 放置规则速查

| 我要加的东西 | 放哪里 |
|---|---|
| 一个新页面 | `web/src/views/XxxView.vue` + 在 `router/index.ts` 注册（需要导航再改 `MainLayout`） |
| 调一组后端接口 | `web/src/api/资源名.ts`，类型与请求函数同文件 |
| 与 UI 框架无关的纯工具 | `web/src/lib/` |
| 跨页面复用的 UI 片段 | `web/src/components/` |
| 一个新后端资源 | `server/src/routes/xxx.ts` 写路由，在 `app.ts` 挂载 |
| 被多路由复用的业务能力 | `server/src/lib/` |
| 数据表/字段变更 | 改 `prisma/schema.prisma` + `prisma migrate dev` 生成迁移 |

## 3. 数据模型

SQLite，Prisma 管理。所有业务表带 `userId`，外键 `onDelete: Cascade`。

- **User**：`username` 唯一、`passwordHash`（bcrypt）。
- **Entry**（每日记录）：`entryDate`（UTC 日期）、`rawContent` 原文、`polishedContent/polishedAt` AI 整理结果、`tags` 与 `photos` 均为 **JSON 数组字符串**（SQLite 无原生 JSON/数组）、`wordCount`。索引 `@@index([userId, entryDate])`。
- **Report**（报告存档）：`yearMonth` 为 key（月报 `2026-08`，周报 `2026-W36`）、Markdown `content`，`@@unique([userId, yearMonth])`。
- **AiConfig**（每用户至多一条）：`baseUrl`、`apiKey`（服务端加密，接口永不下发明文，只回 `hasApiKey`）、`model`、`formality`。

图片不入库：元数据在 `Entry.photos`，文件在卷 `uploads/<userId>/<entryId>/<photoId>`。

## 4. 接口清单

统一前缀 `/api`；除注册/登录外均需 `Authorization: Bearer <token>`；出错统一返回 `{ "error": "中文提示" }`。

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /auth/register · /auth/login | 注册 / 登录，返回 `{token,user}` |
| GET | /auth/me；POST | /auth/change-password | 当前用户 / 改密 |
| GET | /entries | 列表，query：`month` `keyword` `tag` |
| GET | /entries/today | 当日记录 |
| POST | /entries；PUT | /entries/:id；DELETE /entries/:id |
| POST | /entries/:id/photos；DELETE | /entries/:id/photos/:photoId |
| POST | /entries/tags/rename · /entries/tags/delete | 标签批量维护 |
| GET | /photos/:entryId/:photoId | 读取图片（带鉴权） |
| POST | /ai/polish | 单条口语 → 书面整理 |
| POST | /ai/monthly · /ai/weekly | 生成月/周报并存档 |
| POST | /ai/continue | AI 续写/追问 |
| GET·PUT·DELETE | /ai-config；POST | /ai-config/test（连通性测试） |
| GET | /reports · /reports/:key；PUT·DELETE | /reports/:key | 报告存档 CRUD |
| GET | /stats/overview | 仪表盘聚合 |
| GET | /backup/export；POST | /backup/import | JSON 备份/恢复 |
| GET·DELETE | /logs | 运行日志 |
| GET | /health | 健康检查（免鉴权） |

## 5. 关键约定（开发必读）

1. **数据隔离**：每个查询都必须带 `userId` 过滤；取单条资源先查归属再操作。
2. **改表必迁移**：改 `schema.prisma` 后执行 `npx prisma migrate dev --name xxx`，迁移文件随代码提交；**不要**用 `db push` 代替（线上只认 migrations，漏迁移会导致 P2022 列缺失、接口 502）。
3. **错误返回**：路由 catch 后返回 `res.status(4xx/5xx).json({ error: '中文' })`；前端 `lib/http.ts` 统一弹错，业务代码不要重复弹窗。
4. **密钥边界**：AI API Key 只在服务端加解密，前端永远拿不到明文；JWT 由 `JWT_SECRET` 签发，有效期 7 天。
5. **前端分层**：View 不直接写 axios，一律走 `api/`；可复用逻辑进 `lib/`，全局状态进 `stores/`。
6. **路径别名**：前端统一用 `@/...`（指向 `web/src`）。
7. **UI 文案**：全部中文；品牌信息（公司/事业部/组）只出现在登录页、侧栏角标、设置"关于"、报告落款，不干扰记录效率。
8. **样式令牌**：颜色/间距/圆角先查 `assets/tokens.css`，深浅色模式靠 CSS 变量，勿在组件里硬编码色值。
9. **长耗时接口**：AI 生成可能超过 60s，前端 axios 超时 90s、反代 120s，调整时三处一起改。

## 6. 页面与功能地图

| 路由 | 页面 | 主要职责 |
|---|---|---|
| /dashboard | 数据仪表盘（首页） | 连续记录天数、7 天趋势、标签分布、月报状态 |
| /today | 今日记录 | 多条随手记、语音、照片、草稿自动保存、Ctrl/⌘+Enter、AI 整理 |
| /calendar | 日历视图 | 按月查看有记录日期与标签 |
| /list | 记录列表 | 月份/关键词/标签筛选、标签管理、CSV 导出 |
| /reports | 工作汇总 | AI 周报/月报、存档管理、Markdown/CSV/标准 .docx 导出 |
| /settings | 设置 | AI 配置与测试、账号改密、备份恢复、提醒、暗色模式、模板、日志 |

PWA：`public/manifest.webmanifest` + `sw.js`，仅生产构建注册（开发不注册以免干扰热更新）。
